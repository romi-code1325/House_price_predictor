# Real Estate Price Predictor

A Random Forest model + Streamlit app that predicts a home's price from its
features (square footage, bedrooms, location, school rating, etc.).

Built for a 12-hour hackathon: fully offline (no dataset download, no API
keys), so nothing can fail due to a flaky network mid-demo.

## Setup (run once)

```bash
# 1. Create a virtual environment (recommended)
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux

# 2. Install dependencies
pip install -r requirements.txt
```

## Run

```bash
# Step 1: train the model (generates housing_data.csv + model.joblib)
python train_model.py

# Step 2: launch the app
streamlit run app.py
```

This opens a browser tab at `http://localhost:8501` with the interactive demo.

## Login / signup

The app now opens on a login/signup screen (`auth.py`). This is a
lightweight, local-only auth system built for demo purposes:
- Usernames/passwords are stored in a local SQLite file, `users.db`
  (created automatically on first signup)
- Passwords are salted and hashed (SHA-256) — not plaintext, but also
  not production-grade security (no password reset, no rate limiting)
- Create an account on the "Sign up" tab, then log in on the "Log in" tab

## Map tab

The "Find prices near a location" tab lets you pick a distance from the
city center and see:
- Nearby synthetic listings plotted on a map (`st.map`, no API key needed)
- A price estimate for a "typical" home at that distance

The synthetic dataset places listings around a reference city center
(defaults to coordinates in `train_model.py` — change `CITY_CENTER_LAT`
/ `CITY_CENTER_LON` there to your own city, then re-run `train_model.py`).
This is not real GPS/geolocation — it's a demo-friendly approximation,
since a real "find my location" map would need a paid mapping API key.

## Prediction history + price/sqft

Every prediction made in the **Predict a price** tab is logged to your
account (in `users.db`) along with a computed price-per-square-foot
figure. View it any time in the **My history** tab, or clear it with the
"Clear my history" button.

## Clickable listing details

In the **Dataset exploration** tab, both scatter charts (Price vs. Square
Footage, Price vs. Distance to City) are interactive Plotly charts —
click any point to reveal that listing's seller name, contact number,
address, BHK, and price in a details card below the chart. All contact
details are synthetic/fake, generated by `train_model.py`, purely for
demo purposes.

## Project files (each generates the next)

Run in this order:
1. `train_model.py` → creates `housing_data.csv` and `model.joblib`
2. `app.py` (via `streamlit run app.py`) → the actual UI
3. `users.db` is created automatically the first time someone signs up

## How it works

1. **Data**: `train_model.py` generates 3,000 synthetic-but-realistic
   listings (sqft, bedrooms, bathrooms, age, distance to city, school
   rating, crime index) with a price formula plus random noise — so the
   model has real signal to learn from, not pure noise.
2. **Model**: trains a Linear Regression baseline and a Random Forest,
   picks the Random Forest (usually better R²), and saves it with
   `joblib`.
3. **App**: `app.py` loads the saved model, gives you sliders for each
   feature, and shows a live price prediction plus a rough uncertainty
   range and a feature-importance chart.

## Demo script (~3 minutes)

1. Open the app, sign up for an account on screen, then log in.
2. Briefly explain the problem: "predicting home prices from listing
   features using ML."
3. In the **Predict a price** tab: set sliders to a small, old,
   far-from-city home → predict → point out the low price. Then set
   sliders to a large, new, central, good-school home → predict → point
   out the much higher price. This contrast is the "wow" moment.
4. Point at the feature-importance chart — explain which factors matter
   most to the model.
5. Switch to the **Find prices near a location** tab: move the distance
   slider and show the map updating with nearby listings + a live price
   estimate.
6. Switch to **My history** — show that every prediction gets logged
   automatically, with price-per-sqft calculated.
7. Show the scatter charts in **Dataset exploration** — click a point
   live on stage to reveal the (fake) seller's contact card. This is a
   strong visual moment for judges.
8. Mention the R² and MAE metrics as your model-quality evidence.

## Notes / things you can customize fast if you have spare time

- Swap the synthetic data generator in `train_model.py` for a real Kaggle
  CSV if you find one you like — just make sure column names match what
  `app.py` expects, or update both files.
- To add a "compare two properties" feature, duplicate the input form
  into two columns — but only do this if Phases 0-4 are already done
  and stable.
